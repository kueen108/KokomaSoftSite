# 플레이 검증 기록

## 2026-09-14 · 그림 중심 UI

전투·메뉴·모드·지도·출정·기사단·결과 화면의 문구를 줄이고 ⓘ 설명 팝업으로 이동했습니다. 새 그래픽은 기존 캐릭터 이미지와 로컬 SVG로 구성하며 외부 아이콘 서비스나 폰트를 요구하지 않습니다.

- `npm run test:visual-ui`: 데스크톱 1280×720, 모바일 844×390의 화면 8종씩 검사. 기본 전투 화면의 표시된 한글은 전장 이름 5자뿐이며, 초상·게이지·아이콘·숫자로 상태를 표시합니다. 이는 첫 전장의 기본 화면 측정이며 경고·팝업 문구를 포함하지 않습니다.
- 전투의 17개 상시 ⓘ와 아이콘 알림의 ⓘ, 이야기, 모드, 난이도, 병종 능력치, 아우라 성장, 무기·방어구 설명을 실제 클릭해 검사했습니다. 설명은 소환·구입을 실행하지 않습니다.
- 팝업 중 시간·골드·HP 정지, 닫은 뒤 재개, 이미 정지한 상태 보존, ESC·배경·닫기 버튼, 포커스 복원·배경 입력 차단을 확인했습니다. 모바일 팝업이 화면 안에 들어갑니다.
- `npm run test:polish`, `test:expedition-features`, `test:vitality`, `test:scroll`, `test:runtime` 통과. 기존 문장 문자열을 검사하던 항목은 같은 수치·동작과 새 팝업 위치를 검사하도록 갱신했습니다.
- `npm run test:coverage`: 483개 통과. `npm run lint`, `npm run build` 통과. 프로덕션 빌드에서 디버그 핸들 없이 소환·설명 팝업·일시정지·귀환을 확인했습니다.

근거: `artifacts/runtime/visual-ui/report.json`과 같은 디렉터리의 데스크톱·모바일 캡처. 실제 휴대폰 하드웨어 성능 검사는 포함하지 않습니다.

## 열두 전장의 실제 규칙 실행

## 캐릭터·무기·장비

- 신규 6종의 이동 36개·전투 72개 포즈는 모두 다른 이미지이며, 런타임 배경 픽셀은 투명합니다. 기존을 포함해 이동 110개·전투 216개 포즈를 확인했습니다.
- 화염은 주 대상과 가까운 추가 3명까지만 피해를 주고 범위 밖 적에게는 주지 않습니다. 밀집한 적 7명 중 실제 피해 대상이 4명임을 검사했습니다. 장창은 첫 대상 중복 충돌을 무시하고 두 번째 대상 타격 후 사라집니다.
- 장착한 서리 지팡이가 서리 투사체를 생성하고, 적의 이동을 늦춘 뒤 2초 후 복귀합니다. 서리 망령은 루미의 이동도 늦춥니다. 폭탄은 루미와 가까운 동료에게 함께 피해를 줍니다.
- 천둥 전쟁망치는 실제 장착 후 마나 비용 28·간격 850ms·피해 28의 폭발 투사체를 생성합니다. 두 적에게 피해가 적용됩니다.
- 치유사는 루미를 포함한 범위 안 부상자 중 체력 비율이 낮은 최대 3명의 실제 HP를 회복합니다. 부상자 6명 중 3명만 각 8 HP를 회복함을 검사했습니다. 최대 HP 초과와 사망한 캐릭터 부활은 허용하지 않습니다.
- 대방패 장착 시 HP 240·원 피해 40→실제 피해 30. 생명 성의 장착 시 HP 180, 40 피해 후 1,999ms까지 회복 없음, 이후 실제 회복 시간 1초에 +4 HP를 확인했습니다.
- 무기·방어구 구입, 소유 장비 무료 재장착, 선택 결과의 재접속 복원을 실제 기사단 UI로 검사했습니다. 이전 저장의 클리어 기록에 해당하는 신규 동료도 합류합니다.

## 아우라와 화면

- 성장 조건: 전장 3/6/9 클리어와 비용 130/230/330. 부족한 골드·미클리어 조건·최고 단계에서 추가 구입이 막힙니다.
- 각 단계의 실제 범위 220/250/285/325와 아군 공격·이동 증가, 받는 피해 감소, 적 약화 수치의 변화를 검사했습니다. 기존 경계 포함·이탈 복귀·갱신 중첩 방지·보스 단계 변경 검사도 유지했습니다.
- 회전하는 호와 고리·입자 명령이 시간에 따라 달라지고, 일시정지 시 동일하게 동결됩니다. 데스크톱·모바일 화면에서 새 그림, 체력, 장비, 아우라를 확인했습니다.
- 지역 탭과 12개 카드, 잠긴 전장의 진입 차단, 시작 이야기·종료 후일담·최종 결말, 기사단 스크롤, 모바일 8개 소환 카드의 화면 내 배치를 검사했습니다.

## 밸런스 비교

최종 전장까지 실제로 얻은 동일한 성장 상태(아우라 III, 대방패, 수호병·궁수·화염술사 강화 3)로 비교했습니다. 단일 병종 비교에도 루미의 이동·무기·파동 지원을 사용합니다. 전투 시간을 단축하거나 승패를 강제로 만들지 않았습니다.

| 최종 전장 편성 | 난이도 | 소요 시간 | 루미 최저 HP | 결과 |
|---|---|---:|---:|---|
| 혼합 병력 | 이야기 | 141초 | 228.0 / 240 | 승리 |
| 혼합 병력 | 일반 | 147초 | 199.0 / 240 | 승리 |
| 혼합 병력 | 도전 | 151초 | 103.0 / 240 | 승리 |
| 수호병 위주 | 일반 | 188초 | 130.4 / 240 | 승리 |
| 화염술사 위주 | 일반 | 165초 | 205.4 / 240 | 승리 |

혼합 편성이 이 측정에서 가장 빨랐으며 다른 편성도 완주했습니다. 하나의 자동 조작 정책에 대한 결과이므로 전체 전략의 우열이나 사람의 난이도 평점을 뜻하지 않습니다. 일반 난이도에서 무조작은 1/4/7/10번 전장 모두 패배했습니다. 처음 발견한 4번 수호 임무의 무조작 승리는 격퇴 목표 추가 후 재현되지 않았습니다.

기본 성장의 생존 모드 자동 플레이는 393초에 패배까지 진행했고 활성 적 최대 89명이었습니다. 후반 병종을 섞어 원거리 병력과 근접 대열만으로 장시간 정체되는 상황을 줄였습니다. 화면 밖 무제한 증원은 기존 입장 상한으로 막습니다.

## 실제 시간 실행과 한계

12번 전장을 실제 시간으로 별도 실행하여 138.8초에 승리하고 240 골드를 저장했습니다. 60초 무렵 화면 객체 113개, 약 60.5 FPS를 관측했습니다. 첫 10초를 제외한 128개 표본의 평균은 60.5 FPS, 최저는 59.9 FPS, 최대 화면 객체는 131개였습니다. 브라우저 오류는 없었습니다. 데스크톱 Chrome의 이번 실행 측정이며 실제 휴대폰 성능 보장이 아닙니다.

실제 휴대폰, 다양한 저사양 환경, 음원 청감 및 장시간 플레이의 재미는 자동 검사만으로 증명하지 않습니다. 개별 능력·장비 검사에서는 재현을 위한 격리된 상태를 설정했고, 12전장 진행 검사는 신규 저장의 실제 보상만 사용했습니다.
