## 현재 보고서

아래 경로는 모두 `artifacts/runtime/` 기준이며 격리된 브라우저 저장을 사용합니다. 사용자의 저장 데이터는 초기화하지 않았습니다.

- `growth/report.json`: 의상·애니메이션 단계 유지, 충돌 영역·발 위치, 피격 후 이동 보존, 단계별 실제 체력과 적에게 가한 피해.
- `frontline.json`: 적 몸체 경계 정지, 방어 자세, 200ms 후퇴 약 52px, 적 제거 후 전진.
- `cadence-normal-1200-2400-phase0.json`: 12개 전장, 실제 획득 보상과 구매 기록, 피해·손실 기록.
- `cadence-normal-1200-2400-phase400.json`: 마지막 전장 판단 시점 변경, 141초 승리.
- `polish-balance.json`: 10개 난이도·병력·방치·돌진 비교.
- `report.json`: 기본 전장 1–3, 보스, 생존, 방치와 메뉴/경제/재시도 흐름. 생존 검사 최대 적 86명, 제한 96명 이내.
- `expedition-features.json`, `vitality-report.json`, `polish-features.json`, `visual-ui/report.json`: 장비·전투·저장·입력·도움말 회귀 검사.
- `i18n/report.json`, `i18n/report-fr-FR-ko-KR.json`: 전체 언어와 마지막 문구 변경 확인.
- `expedition-realtime.json`: 실제 시간으로 마지막 전장 153.3초 승리, 평균 60.52 FPS / 최소 표본 60.02 FPS, 최대 장면 객체 134개, 최대 적 57명, 브라우저 오류 없음.

## 검증 범위와 한계

실시간 수치는 이 Mac의 데스크톱 Chrome 측정값입니다. 모바일 크기·터치 검사는 자동화된 브라우저 검사이며 실제 휴대전화 성능이나 사람마다 다른 난이도 체감을 보증하지 않습니다. 실제 기기와 사용자 플레이 테스트는 출시 전 별도 품질 확인 항목입니다. Phaser가 포함된 번들 크기 경고는 남아 있지만 빌드는 성공하고 위 실행 검증을 통과했습니다.

이미지는 기본 제공 이미지 생성 기능으로 제작했습니다. 저장 경로와 전체 프롬프트는 [GROWTH_ART_PROMPTS.md](GROWTH_ART_PROMPTS.md)에 있습니다. 상세 작업 이력은 [GROWTH_BALANCE.md](GROWTH_BALANCE.md)에 남겼습니다.
